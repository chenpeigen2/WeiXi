# WeiXi · 玩不死的泡泡龙

泡泡龙射击消除 + 经典三消融合的零挫败解压游戏。

- 没有 Game Over
- 自由换色 / 双击换色
- 愿望卡、星星能量、Fever、特殊泡泡
- 每日挑战 + 12 张贴纸册

## 运行

```bash
godot --path .
```

macOS 上如果编辑器启动遇到 MoltenVK 问题，可用：

```bash
/Applications/Godot.app/Contents/MacOS/Godot --path . \
  --rendering-method gl_compatibility \
  --rendering-driver opengl3_angle
```

更多说明见 [启动文档.md](启动文档.md)，玩法规格见 [玩法.md](玩法.md)。
